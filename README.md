# emergency-detection-yolov11

Proyek ini dilatarbelakangi oleh pentingnya waktu respons kendaraan darurat yang idealnya ≤8 menit, namun di banyak kota masih mencapai 9–23 menit akibat kemacetan dan lampu lalu lintas, di mana setiap keterlambatan 1 menit dapat menurunkan peluang keselamatan sekitar 4–5% dan hingga ±13% kematian lalu lintas berpotensi dicegah jika respons lebih cepat. Untuk mendukung solusi tersebut, proyek mata kuliah Visi Komputer ini mengembangkan sistem deteksi kendaraan darurat berbasis YOLOv11 dengan dataset yang dianotasi menggunakan Roboflow, serta diimplementasikan dalam aplikasi berbasis Streamlit agar pengguna dapat melakukan deteksi secara real-time melalui gambar, video, maupun webcam dengan antarmuka yang mudah digunakan.
